# 오늘 뭐 먹지?

냉장고에 있는 재료를 기록하고 유통기한을 챙기는 개인용 웹앱입니다.
브라우저만으로 동작하며 서버도 회원가입도 없습니다.

## 이 프로젝트의 목적

Claude Code와 에이전트 시스템 기획을 익히기 위한 학습용 프로젝트입니다.
앱은 결과물이고, 실제 학습 대상은 **에이전트에게 일을 시키고 그 결과를 검증하는 과정**입니다.

## 기능 (v1)

- 재료 추가 — 이름, 수량, 단위(개/g/ml/봉), 보관 위치(냉장/냉동/실온), 유통기한
- 유통기한이 빠른 순으로 정렬, 기한이 없는 재료는 맨 뒤
- 기한 상태 표시 — `기한 지남` / `D-n` / 날짜
- 수정, 삭제 (삭제 시 확인 창)
- 빈 상태 안내 문구
- 브라우저 `localStorage`에 저장 (key: `todaymeal.items`)

## 기술 스택

| 항목 | 선택 | 이유 |
| --- | --- | --- |
| 프론트엔드 | 순수 HTML + CSS + JavaScript | 빌드 과정 없이 파일 하나로 실행 |
| 파일 구조 | `index.html` 단일 파일 | 코드 전체가 한눈에 보여 변경 추적이 쉬움 |
| 데이터 | `localStorage` | 서버·API 없이 새로고침 후에도 데이터 유지 |
| 외부 의존성 | 없음 | 라이브러리·CDN·npm 미사용 |

## 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다. 설치 과정이 없습니다.

```powershell
start index.html
```

## 디자인

밝은 파스텔톤 카드형 UI. 색은 모두 `:root`의 CSS 변수로 관리하므로, 변수 값만 교체하면 전체 분위기가 바뀝니다.

| 변수 | 쓰임 |
| --- | --- |
| `--bg` / `--card` | 전체 배경 / 카드 배경 |
| `--text` / `--text-soft` | 기본 글자 / 보조 글자 |
| `--primary` / `--primary-dark` | 주 버튼 / 강조 색 |
| `--line` | 구분선, 비강조 배지 배경 |
| `--chill` / `--freeze` / `--room` | 냉장 / 냉동 / 실온 구분 색 |
| `--warn` / `--danger` | 유통기한 임박 / 기한 지남 |

## 만든 과정

| 단계 | 내용 |
| --- | --- |
| 0 | Claude Code 설치, 계정 로그인, Git 설치 |
| 1 | 프로젝트 폴더 생성 |
| 2 | Claude Code 실행, 요청 범위 지키는지 확인 |
| 3 | `CLAUDE.md`에 기술 제약·코드 규칙·작업 규칙 명시 |
| 4 | MVP 구현 — 화면 구성, 번호 매긴 동작 7개, "이번에 하지 않을 것" 명시 |
| 5 | 체크리스트 9개로 직접 검증 |
| 6 | Git 저장소 초기화, 첫 커밋 |
| 6-2 | GitHub 원격 저장소 연결 |
| 7 | 파스텔 카드 UI 적용 (색 → 카드 → 폼·모바일 순서로 분할) |

진행 원칙은 **"돌아가는 것 먼저, 예쁜 것 나중"**이었습니다.
디자인과 기능을 한 프롬프트에 섞지 않고, 각 단계가 체크리스트를 통과할 때마다 커밋했습니다.

## 배운 것

- **명세의 입자 크기가 결과를 정한다.** 카드 색 띠·배지·버튼 스타일 세 가지를 한 프롬프트에 넣었더니 셋 다 조용히 누락됐다. 하나씩 나눠 요청하니 그대로 적용됐다.
- **"완료했습니다"는 검증이 아니다.** `git init`도, 카드 스타일도 에이전트의 보고와 실제 결과가 달랐다. 체크리스트는 결국 사람이 돌려야 한다.
- **빈칸은 에이전트가 채운다.** 프롬프트에 "이번에 하지 않을 것"을 적어 범위를 닫아두지 않으면 요청하지 않은 것까지 바뀐다.
- **영속 컨텍스트와 일회성 대화는 수명이 다르다.** `CLAUDE.md`에 적은 규칙은 `/clear` 이후에도 살아남고, 대화창에서 한 말은 사라진다.
- **되돌릴 수 있으면 과감해진다.** 커밋 간격이 좁을수록 실험적인 요청을 하게 된다. 복구 경로를 먼저 만드는 것이 순서다.
- **직접 하는 게 빠른 일이 있다.** CSS 숫자 하나 바꾸는 작업은 에디터로 여는 쪽이 빠르다. 무엇을 맡기고 무엇을 직접 할지 가르는 감각도 결과물의 일부다.
